# Song Qingyi — Academic Homepage

This repository contains the static source for `https://sqy1225.github.io`.

## Updating the website

- Edit page content in `index.html`.
- Edit colors and layout in `styles.css`.
- Replace `song-qingyi-profile.jpg` to update the portrait while keeping the same filename.
- Replace `Song-Qingyi-CV.pdf` to update the downloadable CV while keeping the same filename.

After committing changes to the `main` branch, GitHub Pages will update the live website.
